# 🤖 Crypto AI Predictor

**Универсальная ML модель** для предсказания LONG/SHORT любой криптовалюты с конкретными уровнями входа, стопа, тейков и расчётом плеча.

## ✨ Возможности

- 🔮 **Предсказание LONG/SHORT** с вероятностью и уверенностью
- 💰 **Конкретные уровни** — Entry, Stop Loss, Take Profit (3 уровня)
- ⚡ **Расчёт плеча** — консервативное/рекомендуемое/агрессивное
- 🕐 **Тип сделки** — Скальпинг / Интрадей / Свинг
- 📈 **Долгосрочный потенциал** — при сильных сигналах
- 🌐 **Любая монета** — BTC, ETH, SOL, TRX, NEAR и др.
- 📊 **342 фичи** на 6 таймфреймах (1m, 5m, 15m, 1h, 4h, 1d)
- 📡 **Live данные** — Binance/Bybit API
- 🦀 **ONNX экспорт** — для Rust inference

## 🚀 Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
pip install optuna onnxmltools  # для обучения
```

### 2. Live предсказание
```bash
python live_predict.py btc        # Bitcoin
python live_predict.py eth        # Ethereum
python live_predict.py sol        # Solana
python live_predict.py trx bybit  # TRX на Bybit
python live_predict.py btc live   # Мониторинг (каждую минуту)
python live_predict.py eth live 30  # Мониторинг каждые 30 сек
```

### 3. Обучение модели
```bash
# Удалить кэш перед переобучением
del models\training_data_cache.pkl

python train.py                   # Optuna (20 trials)
python train.py --trials 100      # Больше trials = лучше
python train.py --fast            # Без Optuna (быстро)
python train.py --gpu --trials 50 # С GPU
```

## ⚡ Расчёт плеча

Модель рассчитывает плечо по формуле риск-менеджмента:

```
Плечо = Допустимый_риск% / Расстояние_до_стопа%
```

| Уверенность | Риск от депозита | Макс. плечо (волатильность) |
|-------------|------------------|----------------------------|
| Высокая (>65%) | 2% | Низкая: 20x, Средняя: 10x, Высокая: 5x |
| Средняя (>58%) | 1.5% | |
| Низкая | 1% | |

## 🕐 Типы сделок

| Тип | Условия | Время |
|-----|---------|-------|
| ⚡ СКАЛЬПИНГ | Высокая волатильность или ТФ расходятся | 5-60 мин |
| 📊 ИНТРАДЕЙ | Средняя волатильность + ТФ согласованы | 1-8 часов |
| 🌙 СВИНГ | Низкая волатильность + сильный тренд на всех ТФ | 1-3 дня |
